    ℹ️ 关于求职追踪

    🔒 数据存储
    所有记录仅保存在你当前使用的这台设备/浏览器的 localStorage 里，不上传任何服务器，别人打开这个页面看到的是空数据。换电脑 / 换浏览器 / 清理缓存前，请先 ⬇ 导出 JSON 备份，再到新环境 ⬆ 导入 恢复。
    🌐 部署到博客后
    第一次在博客打开是空数据（本地 file:// 的数据不会自动带过来），需要导入一次 JSON。博客端是 https，浏览器会禁用 file:// 链接，所以简历路径的"打开"按钮会自动隐藏，仍可"复制"路径。
    💾 建议
    每周或每投一批就导出一次 JSON 备份，防止误清缓存丢数据。
