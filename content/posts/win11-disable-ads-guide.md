# Win11 有效关闭广告和增加浏览速度

> **Windows 优化 / 实用教程**
>
> Win11 的广告明显比之前的多，拖慢了运行速度和网速。接下来从**系统设置、浏览器广告、应用软件广告**三个方面开始清理。

## 🖥️ 一、系统广告去除

### 找到隐私和安全性

打开 Windows 设置，进入「隐私和安全性」。

![Windows 设置界面](/images/win11-clean-1.png)

### 建议：关闭设备加密

先给个建议——**把设备加密关闭**。具体原因有点复杂，但打开它后期出问题会很麻烦，建议直接关掉。

![设备加密设置](/images/win11-clean-2.png)

### 关闭广告相关的隐私选项

言归正传，点击「常规」，按自己需求开关以下选项：

- 允许应用使用我的广告 ID 向我展示个性化广告 → **关**
- 允许网站通过访问我的语言列表来显示本地相关内容 → 按需
- 允许 Windows 跟踪应用启动 → 按需
- 在设置应用中为我显示建议的内容 → **关**

![隐私常规设置](/images/win11-clean-3.png)

### 个性化里的设备使用情况

打开「个性化」→「设备使用情况」，根据自己情况开关。这些选项会影响微软推送的个性化提示和广告。

![设备使用情况](/images/win11-clean-4.png)

### 关闭搜索广告

点击任务栏的搜索图标（或者直接打开搜索），进入搜索设置。

![搜索界面](/images/win11-clean-5.png)

点击「搜索设置」：

![搜索设置入口](/images/win11-clean-6.png)

在隐私设置里，**关闭「显示搜索要点」** 等选项。关闭后搜索框就不会再出现广告了。

![搜索隐私设置](/images/win11-clean-7.png)

## 🌐 二、浏览器广告去除

浏览器广告可以选择**脚本**或者**扩展**来过滤。以下是我实际在用的几个扩展和脚本：

### 扩展：uBlock Origin（红色图标）

这个红色的扩展非常好用——广告拦截利器。**如果某个网页出现异常，就关闭它刷新**，一般这种网站是广告特别多的（靠广告吃饭的站点），看完再打开。

![扩展管理界面](/images/win11-clean-8.png)

### 配合脚本使用

配合去广告脚本就更合适了，能屏蔽各类广告（谷歌、百度、知乎等平台的广告都能拦）。

![去广告脚本列表](/images/win11-clean-9.png)

## 📱 三、软件广告去除

软件广告去除最简单：**打开每个软件的设置，关闭各种推送和热点资讯**。

下面以 360 安全卫士为例：

1. 在三条杠（菜单）处点击，进入设置
2. 找到广告设置，**把广告开关全部关闭**
3. 建议**功能定制也都关闭**，这样就干净了

![360 广告开关设置](/images/win11-clean-10.png)

![360 功能定制](/images/win11-clean-11.png)

> ⚠️ **注意**：360 的使用建议——**不要使用软件管家**，它本身就是最大的广告来源之一。

## 📌 小结

| 类别 | 方法 | 效果 |
|------|------|------|
| 系统设置 | 隐私常规关广告 ID、关搜索要点、关设备加密 | 减少系统级广告 |
| 浏览器 | uBlock Origin 扩展 + 去广告脚本 | 网页广告全拦截 |
| 应用软件 | 各软件设置里关推送/热点资讯 | 告别弹窗广告 |

做完这三步，Win11 的广告会少一大半，浏览速度也会明显提升。**注意软件广告每个软件都要去设置里关一遍**，别只关一个。
