# 篡改猴（Tampermonkey）安装教程：Edge 浏览器图文版

> **浏览器扩展 / 小白教程**
>
> 篡改猴是一款用户脚本管理器，可以让你**个性化修改网页**，借此更方便地使用浏览器。自定义脚本能完美增加浏览器功能，是浏览器极其重要的组成部分。

## 🤔 篡改猴是什么？

篡改猴（Tampermonkey）是一个**用户脚本管理器**，主要在 Edge 浏览器、火狐浏览器等中可用（其他浏览器是否支持可以百度一下）。

> 理论上手机也可以，但实测手机操作比电脑复杂很多，所以这篇教程只讲 **Edge 浏览器** 的安装方法。

## 📥 安装步骤

### 第一步：打开浏览器扩展商店

浏览器右上角有三个点，点击打开后点击**扩展**。

![Edge 浏览器菜单](/images/tampermonkey-install-1.png)

### 第二步：进入扩展商店

点击**获取扩展**，进入 Edge 加载项商店。

![Edge 扩展管理](/images/tampermonkey-install-2.png)

### 第三步：搜索篡改猴

进入扩展商店后可以看见许多浏览器自带的功能，这些都是可以安装的，根据个人情况而定。

点击搜索，输入 **篡改猴**：

![搜索篡改猴](/images/tampermonkey-install-3.png)

### 第四步：添加扩展

点击**获取**，然后点击**添加扩展**，便可以在右上角看见已经添加的扩展了。

![管理扩展](/images/tampermonkey-install-4.png)

安装完成后，点击篡改猴图标：

1. 首先确定它处于**开启**状态
2. 然后点击**获取新脚本**

![篡改猴设置面板](/images/tampermonkey-install-5.png)

## 📜 获取脚本

一般推荐选择第二个网址（Greasy Fork），更好用：

![脚本网站列表](/images/tampermonkey-install-6.png)

![Greasy Fork 首页](/images/tampermonkey-install-7.png)

在这里面可以找到许多脚本，比如：**刷课、跳广告、避开会员**等操作。

![脚本详情页](/images/tampermonkey-install-8.png)

点击**安装此脚本**，安装成功后再次**刷新**要使用的网站，之后就可以使用了。

> ⚠️ **注意**：建议看一下脚本简介，有些脚本有付费功能，按需下载。

## 🔕 关闭脚本

有些脚本如果不用了，可以关闭。在**面板**或者**管理**处都可以关闭：

![关闭脚本](/images/tampermonkey-install-9.png)

## 📌 安装流程速览

| 步骤 | 操作 |
|------|------|
| 1 | 浏览器右上角三个点 → 扩展 |
| 2 | 点击「获取扩展」进入商店 |
| 3 | 搜索「篡改猴」→ 获取 → 添加扩展 |
| 4 | 点击篡改猴图标 → 确定开启 → 获取新脚本 |
| 5 | 在 Greasy Fork 搜索需要的脚本 → 安装 |
| 6 | 刷新网站即可生效，不用时可关闭 |
