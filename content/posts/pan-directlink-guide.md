# 不装网盘客户端也能下载

**起因**：同学发来一个 2 GB 的课程资料包，链接是百度网盘的。我的电脑上没装网盘客户端——也不想装。

网页版点下载，它让我先装客户端；装了客户端，它让我开会员。于是我花了半天研究「怎么绕开这一步」，最后落成两条路。

先泼一盆冷水，把边界说清楚，免得你看完觉得被骗：

**这两个方案解决的是「下载方式自由」，不是「破解限速」。** 直链是文件在服务端的真实地址，拿到它只能让你用自己顺手的下载器（多线程、断点续传、批量排队），速度上限仍然取决于你账号的权限和服务端的策略。脚本作者自己在 README 里写着「建议配合网盘超级会员使用」——非会员照样会被限速。任何号称「永久不限速破解版」的东西，基本可以归到诈骗或病毒那一栏。

![两条路的流程图](/images/pan-directlink-flow.png)

## 🔍 先搞懂「直链」到底是什么

普通下载的链路是这样的：

```
网盘网页 → 点下载 → 网页版：装客户端吧 / 客户端：开会员吧 → 才给你一条真实的文件地址
```

所谓解析直链，就是把最后那一步提前：**不经过网盘的下载入口，直接问服务端要文件的真实地址（一个带签名和过期时间的 URL）**，然后把它丢给浏览器或下载器。

所以直链有两个天然属性：

- **有过期时间**，通常几十分钟到几小时，过期要重新解析；
- **常常带 UA / Referer 校验**，某些网盘要求请求头里带特定标识，否则 403。

这两点决定了后面所有的「踩坑」。

## 🌐 方案一：网页在线解析（零安装，临时救急）

完全不用装任何东西，手机浏览器也能用。我第一次试的就是这条。

### 操作步骤

1. 浏览器搜「网盘直链解析」，找一个**社区在维护、有新版本更新记录**的站点（这类站点寿命普遍不长，别收藏死一个）；
2. 复制对方给的**分享链接和提取码**（形如 `https://pan.baidu.com/s/xxxx` + 4 位码）；
3. 把链接和提取码粘进解析框，点「获取文件列表」；
4. 勾选要下的文件，选「复制直链」或「浏览器直接下载」；
5. 复制到的直链，粘到下载器里新建任务（或者直接浏览器下）。

### 它好在哪 / 差在哪

| 维度 | 实际情况 |
|------|---------|
| 安装成本 | 零，打开网页就行 |
| 账号风险 | 一般不需要登录你自己的账号（**这是最大优点**） |
| 稳定性 | 差。站点经常挂、经常改域名、经常要「关注公众号取暗号」 |
| 广告 | 多，弹窗、跳转、假下载按钮一堆 |
| 大文件 | 支持差，几 GB 的文件经常解析失败或下到一半断 |
| 文件夹 | 基本不支持批量，只能一个个来 |

### ⚠️ 这类站点必须注意的事

- **绝对不要在解析站里输入你的网盘账号密码**。正规的解析只需要分享链接，要你登录的九成是钓鱼；
- 页面上「高速下载」「立即安装」的按钮，多数是广告联盟的假按钮，真按钮通常很小、在表单旁边；
- 解析出来的直链如果是 `http` 的、或者域名长得不像网盘 CDN，别下——可能被中间人替换成别的东西。

一句话总结：**方案一适合「这辈子就下这一次」的场景**。想长期用，得看方案二。

## 🐒 方案二：篡改猴 + 网盘直链下载助手（长期主力）

这个就是我最后留下来的方案。脚本是开源项目 [syhyz1990/baiduyun](https://github.com/syhyz1990/baiduyun)（作者站点「油小猴」，脚本名 `panlinker.user.js`，AGPL-3.0），本质是一个**油猴脚本**——它接管网盘网页，在页面上给你加一个「下载助手」按钮。

> 为什么强调开源：这类工具最大的风险是「打包了后门」，能自己看代码、能在 GitHub 上追提交记录的，至少是可以复核的。

### 它支持哪些网盘

官方 README 写的是六大网盘：

| 网盘 | 支持 | 备注 |
|------|------|------|
| 百度网盘 | ✅ | 分享页 + 我的网盘，支持勾选文件夹 |
| 阿里云盘 | ✅ | 需登录自己账号 |
| 天翼云盘 | ✅ | 单文件 / 分享 |
| 迅雷云盘 | ✅ | — |
| 夸克网盘 | ✅ | — |
| 移动云盘 | ✅ | — |

社区衍生版（如 [hmjz100/LinkSwift](https://github.com/hmjz100/LinkSwift)，基于本项目修改）还额外支持 UC 网盘、123 云盘，加起来八九家。功能只会多不会少，按需选一个即可，**不要同时装好几个同类脚本**——按钮会重复注入，命令会执行两遍。

### 安装步骤（Windows + Edge/Chrome）

1. **先装脚本管理器**：扩展商店搜 `Tampermonkey`（篡改猴）装上。Edge 在「加载项」里搜，Chrome 在应用商店搜；装完右上角会出现一个黑方块图标。（详细图文步骤见我另一篇《篡改猴安装教程》）
2. **装脚本**：打开 `https://www.youxiaohou.com/install.html`，点页面上的安装按钮，篡改猴会弹出安装页，确认「安装」。
   - GitHub 打不开的话，官方站点是备选；官方站点也打不开时，GitHub 仓库里直接有 `panlinker.user.js` 原文件，拖进篡改猴管理面板也能装。
3. **验证**：打开 `pan.baidu.com` 并登录，页面右上角（或工具栏）多出一个 **「下载助手」** 按钮 —— 成功。

整个过程不装任何网盘客户端，浏览器扩展算「软件」吗？算，但它只是一个脚本宿主，几十 KB，没有后台常驻进程，也不会给你装驱动、开机自启。

### 三种取链方式，按你的环境选

点「下载助手」之后，弹出的菜单里有几种「下载方式」，本质区别是**直链交给谁**：

| 方式 | 适合谁 | 说明 |
|------|--------|------|
| **浏览器下载** | 临时下一个文件 | 直链直接扔给浏览器，最简单，但没有多线程 |
| **cURL 下载** | 不想装下载器的人 | 脚本生成一条 `curl` 命令，复制到终端跑（v5.2.0 起支持） |
| **API 下载（IDM）** | Windows 党 | 推送链接给 IDM，多线程，最稳 |
| **RPC 推送（Aria2/Motrix）** | 极客 / 服务器 | 填好 RPC 地址，链接远程推走，适合挂机下大文件 |
| **BC 下载** | 比特彗星用户 | v5.8.0 起支持 |

**cURL 方式**最适合「什么都不想装」的人。脚本会直接给你一条完整命令，复制粘贴就行，形如：

```bash
curl -L -o "课程资料.zip" "这里是脚本生成的直链"
```

如果自己手拼，记住两点：`-L`（跟随跳转）必须带上，`-H` 里可能要补 User-Agent；下载可以随时 `Ctrl+C`，加 `-C -` 就是断点续传：

```bash
curl -L -C - -o "课程资料.zip" "直链"
```

**IDM 方式**要注意历史遗留问题：早期几款同类脚本要求「IDM 线程数设为 4、User-Agent 改成 `netdisk`」，否则会报 403。现在的直链助手多数情况不用手动改，但如果推送过去一直 403，先翻一眼脚本作者的 Windows 教程，八成就是这个原因。

## ⚖️ 两个方案怎么选

![方案对比](/images/pan-directlink-compare.png)

| 对比项 | 在线解析（方案 A） | 油猴脚本（方案 B） | 官方客户端 |
|---|---|---|---|
| 安装成本 | 0 | 装一个扩展 + 一个脚本 | 一整套客户端 |
| 批量 / 文件夹 | ❌ | ✅ | ✅ |
| 推送到下载器 | 手动复制 | 一键推送 | ✅（仅官方） |
| 稳定性 | 站点随时挂 | 网盘改版后短暂失效，社区会跟 | 最稳 |
| 后台进程 | 无 | 无 | 有 |
| 账号风险 | 低（无需登录） | 中（脚本在自己账号页面跑） | 无 |

我现在的用法是**两个都用**：别人临时发来一个链接、我又不想在自己账号里留痕，就走在线解析；自己网盘里的资料要批量搬走，就开脚本推给 Motrix 挂着。

## 🧯 踩坑清单（都是我真撞过的）

- **直链过期**：解析完别去倒杯水再回来，链接可能已经废了，重新解析一次即可；
- **403 / 401**：先怀疑 User-Agent 和 Referer，其次怀疑链接过期；
- **网盘改版后按钮消失**：脚本更新通常比网盘改版慢几天，等更新或去 Issues 里看有没有临时补丁；
- **别用主账号**：脚本是在你已登录的网盘页面取链，风险理论上可控但仍存在。真要保守，用小号分享 → 用脚本取链 → 下完清空；
- **别买「内部版」「永久破解版」**：这类工具全部开源免费，收你钱的那一方给的多半是加了壳的改包；
- **同时装多个同类脚本**：按钮重复、命令执行两遍、甚至把页面搞崩，装一个就够。

## 📌 小结

> 直链不是魔法，它只是把「文件在哪」这件事从网盘手里拿回到你手里。你可以因此不装客户端、不受网页端 UI 摆布、把下载任务塞进自己顺手的工具里——但带宽和会员，该给的钱一分都省不掉。

**该不该折腾？** 一年下来只下一次网盘文件的人，方案一足够；把它当日常工具的人，花二十分钟把方案二装好，往后省的时间远超这二十分钟。
